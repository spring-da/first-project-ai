# ProcessOn 风格流程图交互重构设计

## 目标

在不改变 `FlowchartDiagram` 持久化结构、保存接口和既有快捷键的前提下，把流程图编辑器的连线编辑改成稳定、可预测的 ProcessOn 风格交互，并同步收紧工具栏、端口、选中态和画布布局。

## 交互模型

1. 选中连线后显示轻量编辑层：拐点为圆形手柄，长水平/垂直段显示短胶囊手柄；未选中连线不显示控制点。
2. 拖动段时锁定该段的垂直方向，按网格吸附并限制最小间距；相邻拐点成对移动，保持路径正交，不让路由器在每一帧改写拓扑。
3. 拖动开始时进入一次 X6 history batch，临时使用显式折线路径作为预览；拖动过程只更新预览，松开后清理冗余点、恢复 Manhattan + rounded 路由并提交一次变更。Esc 恢复拖动前的 vertices/router。
4. 单击路径插入一个拐点；双击拐点删除该拐点（至少保留端点连接所需的最小路径）；拖动端点仍使用 X6 原生磁铁重连。
5. 选中边支持 Delete、方向键微调、Shift 加速；空白点击取消编辑。普通 hover 只改变线宽/颜色，不出现黑色工具块。

## 实现边界

- 新增 DOM-free `flowchartEdgeEditor.ts`，负责正交点清理、段描述、段移动、拐点插入/删除和拖动状态快照。
- `FlowchartCanvas.vue` 使用自定义 SVG/HTML 编辑层，不再使用 X6 原生 `segments` 工具；X6 仍负责渲染、连接、历史、选择、缩放和导出。
- 编辑层坐标由 `Graph.localToClient` 与 Resize/scale/translate/cell-change 事件同步；所有指针监听在卸载、Esc、mouseup 时清理。
- `FlowchartWorkspace.vue` 与 `FlowchartProperties.vue` 只做视觉和布局收紧，不改属性栏数据语义。

## 视觉设计

- 画布工具栏采用分组浮层，工具间距和阴影减弱；选中操作栏靠近选中对象而不是固定占据中心。
- 节点端口默认低对比度，仅 hover/连线时放大；选中节点使用细描边和柔和阴影。
- 编辑层手柄为 8px 白底蓝边圆点/胶囊，命中区域扩大但视觉尺寸不扩大；预览线使用半透明蓝色虚线，最终路径平滑过渡。
- 画布首次打开适配内容并保留安全边距，隐藏属性栏时中央区域自动扩展；窄屏保留只读查看能力和内部滚动。

## 验证标准

- 单元测试覆盖正交点清理、段方向、轴向移动、吸附/边界、插入/删除和拖动取消恢复。
- 隔离浏览器验证：选中边只显示编辑层；拖动中路径不跳变；松开后 vertices 可序列化；单击插点、双击删点、Esc 取消、Delete/方向键有效；缩放/平移/属性栏/导出/历史和 390px 布局无回归。
- `npm test`、`npm run build`、`npm run test:ui:build` 全部通过。
