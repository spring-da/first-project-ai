# 共享池与批量分享验证记录

## 交付行为

- 知识库单篇与批量操作共用分享弹窗，支持文章、代码片段、开发日志混合选择，最多 100 项。
- 登录成员在共享池搜索标题、正文和作者，按类型筛选与分页；分享者可单篇或批量撤下，重复发布不产生重复条目。
- 一个外链可包含全部所选内容，默认 7 天、最多 365 天，访问端按需打开正文。令牌仅创建时返回，数据库存摘要。
- 新外链在共享池的“外链管理”中统一管理；可整条/批量撤销，或仅移除其中一篇。旧单篇链接保留原笔记上的管理入口。
- 原文删除后使相关分享永久失效，恢复原文不自动公开。作者禁用后访客不可访问，管理员仍能代管撤销。共享池与外链独立撤销。

## 浏览器验证

使用生产组件与内存 API，不访问真实账号、数据库或 OSS。

1. 混合勾选三项 → 发布共享池 → 同一窗口切换外链并设置 30 天 → 生成一个链接。
2. 外链管理移除其中的文章后仍保持有效，公开目录只保留片段与日志，正文可读。
3. 共享池批量撤下：取消后保留选择，确认后我的分享为空；外链不受影响。
4. 批量撤销外链后，公开页面显示不可用。五秒到期测试清空已显示正文。
5. 搜索关键词、筛选代码类型、文章图片、代码 HTML 转义、日志链接均可用；公开请求携带账户凭证计数为 0。
6. 管理员进入成员工作区再导航共享池，继续显示成员代管标识并保持成员查询上下文。
7. 单篇文章阅读入口可打开新分享弹窗，并展开旧链接历史。
8. 深浅主题、手机 320/390px，以及共享池平板 1024px/桌面 1440px，无页面横向溢出；浏览器无脚本警告或错误。
