# 桌面流程图工作台重构设计

## 背景与目标

DevNest 的流程图功能将以前端工作台为单位重构，不以现有组件层次或视觉细节为设计前提。目标是提供桌面端专业流程编辑体验：用户先选择合理起点，再进入可折叠的三栏工作台，完成节点、连线、属性、保存、历史和导出操作时始终保持明确的空间关系与状态反馈。

本次参考 ProcessOn 的专业三栏工作台、n8n 的节点库可发现性和 Dify 的渐进式属性编辑，但不复制其品牌、图形或代码。

## 范围

### 包含

- 新建流程图的起始面板：空白画布、模板、导入三条路径。
- PC 专用的三栏编辑器：节点库、无限画布、检查器。
- 节点查找、分类、拖拽/点击创建、最近使用节点。
- 节点与连线的选择、操作条、属性编辑、正交连线编辑和键盘操作。
- 画布缩放、平移、框选、网格、小地图、撤销重做与视口恢复。
- 既有流程图的自动保存、本地草稿、版本冲突、历史、分享、导入与导出。
- 覆盖业务逻辑、数据适配和桌面 UI 的自动化验证。

### 不包含

- 移动端编辑体验；小屏仅维持既有只读或受限入口，不为编辑器做响应式重排。
- 后端接口、数据库表、流程图 JSON 和历史版本格式的迁移。
- AI 自动生成流程图、多人协作、评论或新的图形类型。

## 信息架构

```text
知识库
  └─ 新建流程图
       └─ FlowchartStarter
            ├─ 空白画布
            ├─ 模板
            └─ 导入
                 └─ FlowchartEditorShell
                      ├─ 顶栏：标题、保存状态、模板、历史、导出、分享
                      ├─ NodeLibraryPanel：分类、搜索、最近使用、节点列表
                      ├─ FlowchartCanvas：无限画布、节点、连线、选择与视口
                      └─ InspectorPanel：画布 / 节点 / 连线属性、快捷帮助
```

`FlowchartEditorShell` 只承担布局、权限、离开保护和顶层命令协调。画布、节点库和检查器拥有独立清晰的输入与输出；所有编辑操作经由一个前端编辑会话进入保存协调器，画布不会直接请求网络。

## 新建起始面板

用户点击“新建流程图”后先进入 `FlowchartStarter`，而不是直接落入空白画布。面板以三个同等可识别的入口呈现：

1. **空白画布**：创建包含默认标题与空图的文档，直接进入编辑器。
2. **模板**：展示审批、决策和架构等模板卡片，卡片包含缩略预览、用途和节点数量；选择后以模板的兼容 JSON 创建新草稿。
3. **导入**：打开现有 `.flowchart.json` 文件；文件校验成功后将其作为新草稿载入编辑器。

起始面板可被关闭而不创建草稿。选择路径后，标题自动聚焦，避免用户在无标题状态下离开或保存。

## 三栏工作台

编辑器固定为桌面端三栏结构：左侧 `NodeLibraryPanel` 默认为 264px，右侧 `InspectorPanel` 默认为 320px，中间为弹性画布。两个侧栏都可独立折叠；折叠状态按用户和工作区保存，恢复时不改变流程图 JSON。画布始终占据剩余空间。

顶栏始终包含返回、可编辑标题和明确保存状态。选择、平移、撤销/重做、缩放、适应画布、网格、小地图仅保留在画布内紧凑工具条。历史、导出、分享、模板等次级动作收纳在顶栏，避免画布工具条膨胀。

### 节点库

节点库按流程、基础、数据、标注分类，并提供全文搜索和最近使用区。单击节点会在当前可视区域中心创建节点；拖拽可精确决定落点。节点库中的每种图形均有图标、名称与可访问说明，拖拽不作为唯一创建方式。

### 画布

画布使用低对比度点阵背景、可切换网格、稳定选中描边和克制阴影。节点端口默认低调，在节点悬停、选中或开始连接时显示。画布支持：

- 单选、多选和框选；
- 鼠标滚轮平移，Ctrl/Cmd+滚轮缩放，空格临时切换为平移；
- 适应内容与小地图定位；
- 节点拖动、对齐、置顶/置底和复制粘贴；
- 从端口拖出连接预览，再放到目标端口完成连接；
- 可预测的正交路径、拐点和线段手柄编辑。

选中节点或连线后，画布显示靠近对象的浮动操作条，而不是固定占据画布中心。未选中对象时，检查器展示可操作的快捷帮助。

### 检查器

检查器随选中状态切换为四种视图：画布设置、节点属性、连线属性和快捷帮助。属性更新实时反映在画布上，输入焦点、禁用状态和错误信息均有清晰反馈。侧栏关闭时，选中对象继续可通过浮动操作条执行常用命令；重新打开后保持选择与滚动状态。

## 交互与可访问性

### 快捷键

- `Delete`：删除选中对象；
- 方向键：微移选中节点或连线；`Shift` 加速；
- `Ctrl/Cmd+S`：手动保存；
- `Ctrl/Cmd+Z` 与 `Ctrl/Cmd+Shift+Z`：撤销与重做；
- 空格：临时平移；
- `Esc`：取消连线、拖动或关闭非阻塞浮层。

所有图标按钮拥有可访问名称、可见键盘焦点和不小于 32px 的桌面点击区域。拖拽动作具有单击创建、工具条或键盘替代方式；色彩不会作为唯一状态提示。非关键动效仅使用 `transform` 和 `opacity`，并服从 `prefers-reduced-motion`。

### 连线

连线继续以正交边为默认值。连线时显示目标端口的可连接状态。选中连线显示拐点和长线段手柄；点击线段插入拐点，双击拐点删除，拖动线段保持轴向，拖动途中显示预览路径，松开后一次性写入标准化路径。`Esc` 完整还原拖动前的顶点与路由。

## 数据与保存

流程图后端 API 和持久化结构保持不变。新增的前端模块通过适配层读写 `FlowchartDiagram`，因此已有文档、历史版本、导入文件和分享链接不需要迁移。

编辑会话持有唯一的内存草稿与撤销栈。画布、节点库与检查器提交纯编辑命令，编辑会话生成新草稿；保存协调器按现有策略进行本地草稿备份、防抖云端保存、失败重试与版本冲突处理。顶栏状态固定区分“已保存”“正在保存”“已本地备份、待重试”“版本冲突”，且在离开时复用现有保护逻辑。

导出仅渲染图形本身，不包含编辑手柄、浮动操作条、选中框、小地图或检查器。

## 组件边界

| 模块 | 责任 | 不负责 |
| --- | --- | --- |
| `FlowchartStarter` | 起始路径、模板预览、导入入口 | 画布编辑、网络保存 |
| `FlowchartEditorShell` | 三栏布局、顶栏命令、离开保护、保存状态 | 图形几何、X6 细节 |
| `NodeLibraryPanel` | 分类、搜索、创建意图、最近使用 | 流程图持久化 |
| `FlowchartCanvas` | 渲染、选择、视口、图形与边交互 | 文档标题、网络请求 |
| `InspectorPanel` | 针对选中对象的属性表单 | 画布坐标与路由 |
| 编辑会话/保存协调器 | 草稿、命令、撤销、自动保存、冲突 | 组件布局与 DOM |
| 适配层 | JSON 与 X6 单元之间转换 | UI 状态与业务决策 |

## 错误处理

- 导入失败：在起始面板内说明格式、大小或解析问题，并保留用户继续选择其他路径的能力。
- 保存失败：不丢弃内存草稿，先尝试本地备份，再在顶栏提供重试、导出和读取云端版本的恢复路径。
- 版本冲突：停止自动覆盖，保留本地草稿并明确提供另存副本、导出或读取云端版本。
- 画布初始化或渲染失败：显示可恢复错误状态，提供重试与导出当前草稿的入口。

## 验证

1. 纯逻辑测试：模板生成、节点库过滤、画布命令、路径标准化、保存会话、导入导出与冲突处理。
2. 组件合约测试：起始面板路径、三栏与折叠状态、检查器状态、快捷键、连线编辑层和导出隔离。
3. 隔离 UI 回归：空白/模板/导入路径，节点点击和拖拽，连线、撤销重做、保存状态、历史、导出及 1280px/1440px 桌面布局。
4. 完整验证：`npm test`、`npm run build`、`npm run test:ui:build`。

## 交付标准

- 用户不会在新建时直接面对无指引的空白画布。
- 编辑状态始终有明确的选择、保存和恢复反馈。
- 三栏在 1280px 以上桌面视口中不重叠、不横向溢出，侧栏折叠后画布自动扩展。
- 旧流程图可打开、编辑、保存、历史恢复、导入、导出与分享。
- 完整验证通过，且现有非流程图功能不受本次改动影响。
