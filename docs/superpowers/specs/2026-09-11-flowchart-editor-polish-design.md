# 流程图编辑器交互与布局优化设计

## 目标

改造流程图编辑器，使属性栏按需出现、滚轮手势符合画布编辑器习惯、编辑区域填满可用空间，并改善连线路径拖动的视觉反馈；保持现有流程图 JSON schema、保存流程、导出和历史版本兼容。

## 交互设计

1. 属性栏默认关闭。普通单击只更新选中状态，不自动占用右侧空间。
2. 双击或右击图形/连线时选中目标、阻止浏览器原生上下文菜单、打开属性栏并聚焦文字字段。
3. 工具栏和属性栏标题均提供显式开关。显式打开后保持显示；关闭后画布立即扩展。点击空白清空选区，并在属性栏不是显式固定状态时自动收起。
4. 普通滚轮在画布内平移视口；按住 Ctrl（macOS 同时接受 Meta）时由 X6 以鼠标位置为中心缩放。侧栏和属性表单保留浏览器原生滚动。
5. 正交连线继续使用可序列化的 `vertices`，采用带圆角的 Manhattan 路由和更轻量的顶点/线段控制点；连接端点高亮、选中线宽和 hover 状态保持明显但不遮挡路径。

## 布局设计

- 编辑器外层在 writing mode 中使用 `display:flex; flex-direction:column; min-height:0; height:100%`。
- 画布行使用 `flex:1; min-height:0`，去除固定 `560px` 高度和由此产生的底部空白。
- 左侧图形库保持紧凑固定宽度，中央画布占据剩余宽度，属性栏按需以约 288px 侧栏显示；隐藏时不保留空列。
- 现有主题变量、窄屏只读策略、键盘操作和可访问性名称全部保留。

## 实现边界

- 修改范围：`FlowchartWorkspace.vue`、`FlowchartCanvas.vue`、`FlowchartProperties.vue`，以及必要的流程图交互纯逻辑测试。
- 不新增依赖、不改变后端接口或 `FlowchartDiagram` 类型。
- X6 原生 History/Selection/Transform/Export/Dnd 继续作为底层能力。

## 验证标准

- 默认打开编辑器时右侧属性栏不存在；双击/右击后出现并可编辑文字。
- 普通滚轮不改变 zoom；Ctrl+滚轮改变 zoom；侧栏滚动不触发画布缩放。
- 属性栏关闭后画布占满横向与纵向可用空间，宽屏和窄屏无横向溢出。
- 正交线的顶点和线段可拖动，控制点不再呈现黑色粗块，保存/重新打开后顶点仍保持。
- `npm test`、`npm run build`、`npm run test:ui:build` 均通过。
