## 流程图隔离回归（2026-09-10）

此入口继续挂载生产 App、KnowledgeView、FlowchartWorkspace 和 FlowchartCanvas（AntV X6），没有另写画布或编辑器。流程图摘要与正文分开存放；列表、搜索、回收站和管理员快照不返回 diagram。分享正文按需返回最新已保存图形，content 只含图形与连线文字。文章、JSON、分享管理、管理员及图片场景保持可用。

- `?flowchart=1`：直接阅读七种图形示例，点击“编辑流程图”进行编辑；包含直线、折线、闭环和看起来像 HTML 的纯文本。
- `?flowchart=large`：确定性的 300 图形 / 500 连线画布，包含所有图形类型。检查选择、拖动、缩放、适应、撤销重做及 PNG/SVG/源文件导出。
- `?flowchart=1&flowchart-hold-save=1`：暂停云端保存；修改后保存，继续输入，再通过控制台完成响应。确认新输入保留并再次保存。
- `?flowchart=1&flowchart-conflict=1`：首次更新前模拟另一会话保存，返回 409；检查自动保存停止、“读取云端”和“另存副本”。控制台“模拟其他会话更新流程图”可再次触发。
- `?flowchart-recovery=1` / `?flowchart-recovery=stale`：预置可恢复草稿 / 云端版本已变化的草稿。使用真实生产草稿读取与恢复逻辑；通过全新 fake-indexeddb 内存工厂隔离，不会读取浏览器真实 IndexedDB。另有朋友账号、管理员代管朋友工作区的同文档草稿用于检查身份隔离。刷新重置全部数据。
- `?flowchart=1&flowchart-offline=1` / `&flowchart-rate-limit=1`：模拟断网 / HTTP 429；控制台可切换，恢复联网会触发生产 online 处理器。原有“云端保存故障”和“历史加载故障”控制也适用于流程图。
- `?flowchart=1&flowchart-create-retry=1`：新建流程图后首次服务端响应丢失，重试同一 creationKey 应返回同一份文档，无重复创建。
- `?knowledge-items=30&directories=6`：流程图替代日志参与统一列表、标签文字搜索、收藏、批量移动及删除。混合移动在版本校验全部通过后才修改数据。
- `?shared-pool=1` / `?public-bundle=1`：流程图与文章、代码共同分享；检查懒加载只读画布、最新保存内容。移入回收站时永久撤下原共享记录与外链条目，恢复文档后原链接不重新生效。
- `?admin=1&admin-data=35`：管理员快照使用流程图摘要，单份正文单独加载；管理员代管仍沿用按成员隔离的内存数据。
