## 浏览器验证

使用真实生产组件和内存 API 夹具，在 Chrome 中检查；核心编辑、保存、知识管理和大图也使用生产优化后的隔离构建复测，没有连接真实账号或 OSS。

- 点击/拖入图形各新增一次；端口拖线、文字和样式编辑、尺寸拖拽、样式更新后文字仍垂直居中、复制粘贴、删除、撤销/重做、重新打开和源文件导入往返保持内容一致。
- 保存响应暂停时继续输入后顺序提交；断网保留草稿并在重连保存；创建成功但响应丢失的重试不重复建图，继续编辑不会被旧创建响应覆盖。
- 多会话冲突停止写入，另存保留双方版本；连续输入在 15 秒以内开始提交，缩放不产生内容版本；手动历史预览和恢复、模板与快捷键正常。
- 可恢复旧草稿不会覆盖当前未保存草稿；同路由导航在云端及本机存储均失败时出现确认，取消后内容保留。账号/管理员目标切换时，活动请求、草稿及异步响应未串用。
- 节点/连线文字可在知识库和全局搜索命中；人为延迟旧搜索响应后，它无法覆盖更新的搜索结果。三类内容混合移动、收藏、批量删除及流程图回收站恢复正常。
- 共享池和公开集合展示最新云端文字；删除/恢复后旧共享项不复活，混合集合的文章和代码继续可用，匿名请求不携带账号认证。
- 1920/1440px 桌面、1024px 平板、深浅主题，320/390px 手机私有/共享/公开只读布局无页面横向溢出。全屏保留图形库、属性、模板及确认框可操作。
- 未观察到浏览器脚本异常；PNG 解码和 SVG 内容检查通过，已人工查看截图及导出图。

300 节点、500 连线的本机合成图生产构建测量：进入编辑约 2.56 秒；连续拖动/缩放采样帧间隔 P95 约 50 ms；SVG 导出约 0.52 秒，PNG 约 0.59 秒。该数据用于描述本机实测，不代表所有设备或真实网络性能。

## 数据恢复与发布边界

此次数据库恢复演练采用隔离 PostgreSQL 集群内 `CREATE DATABASE ... TEMPLATE ...` 的物理副本，验证的是迁移后可从升级前副本恢复完整状态；没有执行生产 `pg_dump/pg_restore` 或离机灾备演练。真实上线仍须停止写入、取得完整备份并恢复验证，然后同步发布前后端。回退需要升级前完整数据库和兼容 V18 的应用。详见 [数据库升级说明](../../../first-project-back/docs/POSTGRESQL_SETUP.md)。
