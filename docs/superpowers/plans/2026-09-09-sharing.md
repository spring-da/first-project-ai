# 共享池与批量分享 Implementation Plan

**Goal:** 完成内部共享池、混合批量外链和细粒度撤销，并验证权限与用户交互。

**Architecture:** 新分享模块管理内部发布和外链集合，保持旧链接兼容。前端共享弹窗复用现有选择能力，新增共享池/外链管理与公开集合阅读页。

**Tech Stack:** Vue 3、TypeScript 6、Pinia、Java 26、Spring Boot 4.1、PostgreSQL、Flyway。

**Spec:** `docs/superpowers/specs/2026-09-09-sharing-design.md`

## Constraints

- 不覆盖已有用户改动，不操作生产数据或真实 OSS。
- 不存储明文分享令牌；所有者和图片访问均由服务端校验。
- 批量上限 100，外链有效期 1–365 天，保持现有主题和组件。

## Tasks

- [x] 后端（并行独立边界）：按规格新增 sharing 业务层、V18 迁移、HTTP 接口和集成测试；先运行测试确认缺失接口失败，再实现并通过测试；补充 API 文档。
- [x] 前端基础：新增 sharing 类型、服务与 Store；测试引用去重、有效期校验、请求隔离与过期行为，再实现。
- [x] 前端交互：统一分享弹窗、旧链接历史组件、知识库单篇和批量入口、共享池菜单/搜索/我的分享/外链管理及细粒度撤销、公开集合阅读页。
- [x] 联调验证：扩展隔离 UI 夹具，运行 npm test、npm run build、npm run test:ui:build，检查桌面/手机及深浅主题。
- [x] 完成审核：检查跨端契约与安全边界，执行完整后端 test/package、真实 PostgreSQL 迁移验证并记录实际结果。
