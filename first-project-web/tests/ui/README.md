# 通知与 Markdown 编辑器回归

自动化状态测试：在项目根目录运行 `npm test`。

浏览器检查：运行 `npm run dev -- --host 127.0.0.1`，打开
`http://127.0.0.1:5173/tests/ui/notifications-editor.html`。

此页面直接挂载生产代码中的 App、布局、Markdown 编辑器及通知中心；
所有账户、API 响应和浏览器存储均为内存中的测试数据，不连接真实后端，
不读取或修改真实笔记。刷新页面会重置测试环境。该入口不会被生产构建收录。

检查项：

- JSON 与目录优化场景：`?json-editor=1&directories=16&knowledge-items=8`。包含嵌套对象、数组、长整数、带小数位的数字和长目录名。目录 CRUD 全部使用内存模拟。
- JSON 默认分栏显示源码和可编辑结构；检查字段改名、字符串/数字/布尔值修改、切换类型、增删字段、折叠/展开、撤销/重做，保存后再次打开应一致。长整数和未修改数值的小数位必须保持原文。
- 代码区输入 `{` 后 Enter：自动补齐括号并插入两空格缩进；Tab / Shift+Tab 支持多行缩进，按 Esc 再按 Tab 可以离开代码区。
- “加转义”保留实际换行和缩进，不添加整段字符串的外层引号；格式化、结构修改继续保留转义模式。“去转义”还原标准 JSON，也兼容旧版单行转义字符串。无效 JSON 只提示错误，原文保留。
- 目录超宽时自动收纳，展开后搜索与选择隐藏目录，当前目录应回到可见栏。鼠标右键或 Shift+F10 打开编辑/删除菜单，手机可点目录列表里的管理按钮。检查 Esc、外部点击、路由切换和新增/改名后的计数更新。
- 检查 1920/1440px 展开与收起侧栏、1024px 平板、390/320px 手机及深浅主题；源码与结构独立滚动，页面无横向溢出。

- 编辑文章后隐藏搜索和知识库导航、收起侧栏，编辑区占满可用高度。
- 长文的正文与实时预览独立滚动，页面本身不被长文撑高。
- 保存、空正文校验、测试控制台中的草稿/云端故障均显示悬浮通知。
- 消息约 4–6 秒自动消失；鼠标悬停或键盘焦点停留时暂停计时。
- 消息历史、未读筛选、详情、已读、删除及清空操作。
- 深浅主题切换、390/320px 手机宽度、返回列表和 KeepAlive 路由切换。
- 历史版本加载失败使用 Toast，保留刷新按钮，不产生常驻错误横幅。
- 退出、项目/目录/代码/日志删除、草稿无法备份时离开，均使用自定义确认框。
- 确认框默认聚焦取消，Esc 和遮罩取消；Tab 焦点不离开弹窗。
- 搜索范围菜单的鼠标选择、方向键、Esc、Tab 和外部点击；关闭菜单不清空查询。
- 新建未命名笔记按 Ctrl+S：提示命名，焦点到标题，控制台保存请求不增加且快捷键已拦截。
- 填标题或非默认文件名后 Ctrl+S / ⌘S 创建，再编辑后保存：生成云端保存通知，不触发浏览器另存网页。
- 展开/收起侧栏时知识库内容占满剩余区域；大屏不再被 max-width 留出大块空白。
- 使用 `?knowledge-items=60` 检查文章、代码片段和开发日志的统一列表、自定义类型菜单、目录总量角标及 12/24/48 条切换；同时检查三类内容均可勾选，勾选后工具栏切换为自适应批量整理模式，目标目录菜单、混合批量移动、“新增知识”菜单、“新建目录”入口和文章预览标题导航均可用。
- 知识列表右键或悬停“更多”可打开统一操作菜单；文章和代码片段支持收藏，开发日志支持置顶，操作后立即重排。混合选择后可一次确认批量移入回收站。
- 系统工具入口：`?tools=1`，检查 CRON 快捷配置/自由输入/未来运行时间、JSON 结构编辑器与秒/毫秒时间戳互转；JSON 的代码、结构和分栏模式应共同铺满 PC 页面剩余高度。
- 意见交流入口：`?messages=1`，提供 12 条合成消息、链接高亮、折叠回复、进入视口后才请求的鉴权图片和滚动加载，可安全验证粘贴图片优化、发布、回复与删除交互。
- 系统公告入口：`?announcements=1`；追加 `&admin=1` 显示 Markdown 编辑、实时预览、发布与撤回操作，任意登录场景追加 `&unread-announcement=1` 可检查进入系统后的 Markdown 公告弹窗。
- 语法手册默认关闭；打开后正文仍可输入，插入示例和关闭有效；深浅主题/手机宽度正常。
- 测试控制台的“模拟粘贴测试图片”触发真实 paste 处理器；也可使用文件按钮选择合成测试图。图片接口与鉴权读取均模拟，不连接 OSS。
- 暂停图片响应后继续输入并按 Ctrl+S：保存被阻止；完成响应后，图片插入且续写内容保留，预览成功。
- 模拟图片上传故障后，只移除上传占位，不改变其他正文；重新粘贴可重试。
- 在文章预览或已有文章编辑页打开“分享”，设置 1–365 天有效期并生成一次性链接；检查复制、有效链接列表和撤销确认。
- 使用 `?public-share=1` 直接进入未登录的公开只读页；长文可滚动，深浅主题及 390/320px 手机宽度正常，页面不显示工作区导航。

## 普通 HTTP / 生产构建回归

开发入口附加 `?no-random-uuid=1`，会在挂载 App 前移除 `crypto.randomUUID`。
测试控制台展示能力状态、登录请求次数和会话失效事件次数。
打开登录页后使用 `fixture@example.invalid` 和任意假密码：模拟接口始终返回 401，
应显示错误 Toast，且会话失效事件为 0。通知自动消失后应仍在消息历史中。
同时验证 Markdown 修改会正常保存本机草稿，不再误报存储失败。

也可以使用同样的 Vite 生产优化过程构建隔离入口：

```powershell
.\node_modules\.bin\vite.cmd build --config tests/ui/vite.config.ts
.\node_modules\.bin\vite.cmd preview --config tests/ui/vite.config.ts
```

访问 `http://127.0.0.1:4173/tests/ui/notifications-editor.html?no-random-uuid=1`。
测试构建只写入 `.ui-test-dist`，不会替换或混入部署用的 `dist`。

通知存储的刷新恢复、账号隔离、故障降级和清除语义由
`tests/notifications.test.ts` 覆盖。

## 工作台待办卡片回归

`tasks` 支持 0–200 条合成任务；`project=none` 为项目空状态，`project=long` 为超长说明；
添加 `&long-tasks=1` 可检查长任务文本；添加 `&fail-module=projects` 可验证项目加载失败时任务、文章等成功模块仍正常展示并可局部重试。测试任务支持添加、编辑、完成、归档和带确认删除，均不访问真实后端。

- 0、1、40、200 条待办下，两张卡片高度一致，任务数量不改变卡片高度。
- 顶部四张概览卡可分别跳到今日任务、构建中项目、收藏片段和 Markdown 文章；任务页签筛选写入 URL，刷新后保持当前视图。
- 桌面端顶部/底部对齐，标题和添加入口在滚动区外；新增后自动滚到新任务。
- 今天、即将到期、收件箱、已完成和归档视图可切换；日期、截止时间与优先级表单在手机端无溢出。
- 空状态按钮可用，今日完成数量即时更新；删除前显示自定义确认框。

## 人员管理与强制改密回归

- 管理员人员列表：`?admin=1&admin-data=35`，包含管理员、正常用户、禁用用户、待注册邮箱及多页成员工作区合成记录；检查工作区搜索、分页、知识列表与独立阅读区，知识页隐藏统计卡片并让列表和阅读区占满近全屏弹窗；同时检查创建/轮换邀请链接及重置随机临时密码的一次性弹窗、复制和关闭清除交互。
- 强制修改密码：`?force-password=1`，使用任意当前密码与至少 8 位的新密码即可走通隔离流程；普通会话可从“我的 → 修改密码”进入同一页面的常规模式。
- 账户安全与资料：`?profile=1`，检查默认头像、头像上传/恢复、性别编辑、普通退出、退出全部设备及其确认文案；隔离 API 不接触真实登录会话或 OSS。
- 两个入口都只使用内存 API；检查 1440px、390px 和 320px 宽度下菜单、筛选、状态标签和操作按钮无横向溢出。


## 管理员可编辑成员工作区回归

执行 `npm run test:ui:build` 会同时检查隔离夹具类型并构建隔离页面。`?admin=1&tasks=3` 使用真实生产路由守卫和按账号独立的内存数据。

1. 进入朋友账户的“模拟登录 / 管理数据”，验证完整工作台和成员提示条。
2. 修改任务、文章、代码或资料；导航到其他业务页面仍保留成员身份，顶部返回入口在专注编辑时仍可用。
3. 返回人员管理再查看自己的工作台，自己的数据不应出现成员修改。
4. 展开隔离测试控制台，点击“正常登录朋友账户（模拟）”，确认同样的数据和页面，且无管理员菜单或模拟提示条。
5. 通过“恢复管理员登录（模拟）”验证其他成员、禁用成员和退出流程；编辑未保存文章时返回应保留本机草稿，草稿存储故障时应提示确认。
6. 在 1920/1440px、1024px、390/320px 以及深浅主题检查无页面横向溢出。旧的 `?admin-workspace=1` 直达入口继续有效。

所有操作只改变内存数据，刷新会重置；不使用真实账号、数据库或 OSS。
