# DevNest Web

## 文章保护与恢复

- 输入后约 600ms 自动保存**本机草稿**，离开、切换标签页和关闭页面时也会尝试保存。列表上方会显示可恢复草稿；支持继续编辑、另存为新文章和丢弃。
- 草稿按登录账号隔离，并为不同文章/编辑会话使用独立存储键。草稿不等于云端保存：仍需点击“保存文章”；浏览器清理数据、隐私模式或存储配额不足可能影响本机草稿，界面会显示写入失败提示。
- 文章删除后进入“回收站”，不会自动清空；可恢复文章，或经过确认后彻底删除文章及历史版本。
- 编辑页与阅读页的“历史版本”可以预览和恢复快照；恢复会保留其他版本。历史记录从后端升级时的基线及后续保存开始，不包含升级前已丢失的内容。
- 保存使用文章版本号检查冲突；保存期间继续输入的内容会留在编辑器和本机草稿中。遇到冲突可返回列表恢复草稿，并选择“另存为新文章”。

请先部署后端并执行 Flyway V5 迁移，再部署此前端。升级前备份数据库，迁移会为现有文章创建一份基线快照；不要在生产库上使用测试用的 `create-drop` 配置。

回归检查：`npm test`、`npm run build`。手动流程：新建并输入 → 返回/重开 → 恢复草稿 → 保存两次 → 预览及恢复历史 → 移入回收站 → 恢复 → 再删除并彻底删除。另检查保存失败、账号切换、手机布局和长文滚动。

DevNest 的浏览器 PC 端，基于 Vue 3、Vite、TypeScript、Pinia 和 Vue Router 构建。

## 本地开发

建议使用 Node.js 22.12+（当前 Vite 版本不支持 Node.js 20.17）。

1. 启动 `first-project-back`，默认端口为 `8080`。
2. 安装依赖：`npm install`
3. 启动开发服务器：`npm run dev`
4. 打开 `http://localhost:5173`

开发环境会将 `/api` 请求代理到 `http://127.0.0.1:8080`，因此默认不需要额外配置跨域。

## 环境变量

部署时复制 `.env.example` 为对应环境文件，并配置：

```text
VITE_API_BASE_URL=https://api.example.com/api/v1
```

正式环境应使用浏览器可访问的 HTTPS 后端地址。

## 已实现模块

- 邮箱登录、一次性邀请链接注册、注册昵称实时查重与 JWT 会话保存
- 管理员人员管理、代管成员完整工作区、操作审计、短期随机临时密码和强制改密
- 独立的系统公告页与意见交流页：Markdown 公告编辑/预览、公告单次提示、链接高亮、折叠回复、粘贴图片压缩和进入视口后异步读取的鉴权图片
- 文章、代码片段与流程图支持共享池和限期集合外链，只读内容随云端保存更新，支持即时撤销
- 工作台任务计划，支持今天、即将到期、收件箱、已完成和归档视图
- 项目雷达及项目 CRUD
- 领域目录管理，支持采购、财务、制造等业务知识分区
- Markdown 文章创建与编辑，支持写作/实时预览分栏和移动端模式切换
- `.md` / `.markdown` 文件拖放批量导入，以及所选或全部文章 ZIP 批量导出
- 代码片段搜索、收藏、复制、行式分页和 CRUD
- 流程图独立画布、模板、自动保存、历史恢复、收藏、搜索及回收站
- PC、平板与手机 H5 响应式布局，以及深色/浅色主题
- 开发者资料、性别设置、昵称生成的默认头像与私有头像上传
- 个人设置主动修改密码、退出全部设备，以及强制改密模式
- 工作台概览卡和任务页签支持带筛选条件跳转，刷新后恢复当前筛选

工作区的任务、项目、文章、目录、片段、流程图摘要和资料使用独立加载状态。单个接口失败时，已成功模块仍正常展示；失败位置会显示错误与局部重试，不会把网络错误显示成“0 条数据”。

知识库以个人写作和长期沉淀为中心：Markdown 文章、代码片段和流程图共用目录，并按更新时间聚合在同一个列表中；内容类型作为筛选与展示字段，新增时再由用户选择。

## 搜索与外观

- 顶部保留唯一搜索框。知识库和项目页默认搜索当前列表，可切换为全局搜索。
- Markdown 文章在当前列表和全局搜索中都只匹配标题与文件名，不匹配正文或摘要；代码代码片段匹配代码内容；流程图通过服务端搜索标题及节点、连线文字，列表只加载摘要。
- Markdown 编辑器的编辑区和实时预览区独立滚动，长文不会撑开双栏布局；仅编辑、仅预览和手机布局使用同样的滚动规则。
- `Ctrl/Cmd + K` 聚焦搜索；全局结果支持方向键选择、回车打开、`Esc` 清空退出。
- 切换知识类型时保留关键词，切换页面时清空关键词，避免缓存页面残留筛选。
- 统一使用白灰 / 石墨灰底色与蓝色强调，保留已保存的主题偏好；首次访问跟随系统主题。
- `npm test` 运行搜索回归测试，`npm run build` 执行类型检查和生产构建。

## 流程图

知识库通过“新增知识 → 画流程图”创建单画布内容，已有图默认只读预览，电脑可进入编辑；手机可查看、平移、缩放，并在知识列表管理目录、收藏和回收站。X6 3.1.8 按需加载，工作区列表仅缓存摘要。

- 支持标准形状、连接点、直线/折线、箭头、文字样式、对齐辅助、多选、复制粘贴、撤销重做、层级、缩放、网格、小地图与全屏。
- 停止编辑约 2 秒自动保存，连续操作最多每 15 秒提交；可手动保存或按 Ctrl/Cmd+S。保存请求串行执行，新输入不会被旧响应覆盖。
- IndexedDB 本机草稿按登录者、代管工作区、文档和编辑会话隔离。遇到版本冲突暂停自动保存，可读取云端或另存本机版本；断网保留草稿并重试。
- 自动历史检查点间隔至少 5 分钟，手动保存和历史恢复生成检查点；相同内容不重复，最近 100 条，每页 20 条。
- PNG/SVG 导出包含当前未保存改动，默认白底；`.flowchart.json` 导入创建新图，保留图形、文字、连线和样式。上限 5 MiB、1,000 个节点、2,000 条连线。仅接受项目专用数据格式。
- V19 移除旧开发日志表及对应分享关系。发布前备份数据库并验证恢复，同时更新后端与前端；恢复部署需要数据库备份和旧应用。历史审计记录保留。

接口与发布检查见后端 [FLOWCHART_API.md](../first-project-back/docs/FLOWCHART_API.md)，隔离浏览器场景见 [tests/ui/README.md](tests/ui/README.md)。
